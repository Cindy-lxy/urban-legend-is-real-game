# 都市传说是真的？

一款纯静态互动视觉小说，支持章节选择、剧情回看、物品调查、自动存档和多结局。

## 部署优化

- 场景图与线索图已转换为轻量 WebP，工程资源由约 52 MB 压缩至约 1 MB。
- 不依赖外部图片、字体或音频服务，可直接部署到 GitHub Pages。
- 已针对 PC、手机竖屏、手机横屏、刘海屏安全区和弹窗滚动进行适配。
- 游戏进度保存在浏览器本地存储中。

## 文件结构

- `index.html`：页面入口
- `style.css`：界面和响应式样式
- `story.js`：章节、剧情、线索和结局数据
- `game.js`：游戏状态、交互与存档逻辑
- `assets/`：本地 WebP 美术资源
